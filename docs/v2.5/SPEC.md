- P271: Settings section listing every prompt the app uses, editable; implementation centralises
  them in one file so they are easy to update.
- P272: facts use nanoid ids: collision-free, easy to find, idempotent; comments referencing other
  docs cite these ids. One md file holds many facts, each with its own id, so the DB also groups
  facts (from this session, task or whatever); when a fact is needed, the AI asks for its immediate
  context in a second step. Ask the writing agent who decided: it or the user. Store the session
  that added the info. Origin has three states: user, agent, external (tag naming the real source,
  e.g. slack). Grading: human-challenged facts are correct; agent facts are reference; external
  facts are correct but probably incomplete. Scope field: company (company-wide), project (which
  project noted), personal (the user decided it; others need not follow it).
- P273: an MCP flag so a memory is not persisted but prepared and formatted as a code comment;
  strict text format; same atomic ideas with the reasoning behind; regex for the format, runnable as
  a git hook, ensuring all comments are properly done. Same for the file ingester, so all docs files
  in a repo are correct and easy to understand; metadata at the beginning for grep searchability;
  serialisation over text and md files, easy to ingest after first processing. Both formats
  optimised for grep (main way AI finds them) and efficient for AI; humans second, so some
  formatting needed, but e.g. bold can interfere with grep. Facts and reasons short, succinct, easy
  to read, inspired by this repo's communication rules.
- P274: external data (Slack, ...) not ingested via MCP content (costs tokens); first extracted to
  a text file (md, json, ...); the agent calls the memory MCP with the file path. Same for project md
  files: the agent requests ingestion and does not read them. Ingestion chunks, then the memory
  module cross-checks each questionable fact in the file itself, then stores. The ingest MCP is only
  instrumentation. A way to ingest sources that cannot be challenged (Slack, Jira, ...).
- P275: more advanced scoring; combine full-text and vector results meaningfully; bias to return
  more, not less.
- P276: memory MCP docs short, succinct, clear, explain what is expected; e.g. the module extracts
  facts itself, but every fact must come with a reason and user or agent etc., so the provided data
  is complete even if poorly formatted.
