`extractPrompt`, `finalizePrompt`) into one file, so P272-P276 edit prompts there, never twice.

so later rows never touch a prompt twice (`CLAUDE.md` table-position rule). P273 (formats) precedes P274 (ingestion), which emits and
parses those formats. P275 (ranking) needs P272's origin, scope and groups. P276 (MCP docs) runs last
because it documents the final tool surface of P272-P275. Rows run top to bottom, one at a time. P277-P278 fix known problems. P279 adds run resume. docs this chapter writes follow `CLAUDE.md` "Communication style": terse, one idea per sentence,
active voice, no filler, negations and numbers kept, clarity over compression.
