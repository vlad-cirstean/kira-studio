### Wording: "Runs" for the module, "script run" for one run

"Run" already means three things: ADE step runs ("Background run", "ADE run done", "Task runs" in quit confirm),
script runs ("Script runs" in quit confirm, `automations.runs.*`), and Operations history. Rule: the module name is
**Runs**. Wherever one run of a script stands next to an ADE run or a generic list, say **script run**, matching the
existing `workbench.quitConfirm.scripts.label` ("Script runs: {count}") versus `.runs.label` ("Task runs: {count}").
The saved thing stays **script**.
