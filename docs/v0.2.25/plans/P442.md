## Policy

- Latest stable minor/patch for every dependency and tool. Never a nightly, alpha, beta or `-dev` tag,
  except where the repo already sits on one (`@typescript/native-preview`: stays on its `latest` dist-tag).
- A major bump only when low risk: small call surface, no behaviour change hidden behind a compiling
  build. Otherwise list it under "Deferred" with the reason. Decisions already made below; the
  implementer re-checks only majors that appear after 2026-11-01.
- Versions move while work runs (Wails ships weekly). Fix each version at the start of its step, record
  it in the commit, never chase a newer release mid-phase.
- License: every changed dependency, direct or indirect, new or bumped (SPEC row). New: read its
  license. Bumped: confirm license unchanged from the old version. Go: `LICENSE` in
  `$(go env GOMODCACHE)/<module>@<version>`, diff old vs new. JS: `license` field in
  `node_modules/<pkg>/package.json`, old from `git show <base>:bun.lock` resolution. Any non-OSI,
  source-available, non-commercial or dual-licensed result blocks that bump (CLAUDE.md "Only fully
  open-source libraries"). Record the changed set and licenses in Result, one line per family.
- Deliberate pins stay unless their reason is gone: TypeScript 6 (`docs/ARCHITECTURE.md` Stack: TS7 has
  no stable compiler API until 7.1, vue-tsc needs it), go-redis `Protocol: 2` (code setting, not a
  version pin), the flatbuffers triple (below), Docker test images (below).
