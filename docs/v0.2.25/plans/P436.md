# P436 ADE session tab context menu: Close session, Restart session

Stream A, worktree `/home/user/kira-stream-a`, branch `chapter/v0.2.25-stream-a`, base `4d81ca10f`. Ownership and
i18n subtrees: `plans/streams.md` "Stream A". Touch nothing outside it. No npm or Go dependency, no migration.

SPEC row: right click on a session tab offers Close session and Restart session, next to Copy session ID.

## Current state (verified at base, via `codegraph_explore`)

- `frontend/src/ade/v2/sessions/AdeSessionStrip.vue` renders only running sessions (`AdeSessionsTab.vue`
  `running`), `@contextmenu` calls `useSessionMenu().open`.
- `sessions/useSessionMenu.ts` items: Restart (`common.action.restart.label`, only `!view.headless && state ===
  'running'`), Copy session ID. `restarting` reactive set disables Restart while pending. Errors go to
  `ui.actionError[taskId]` (`ade-panel-action-error`).
- Backend `internal/ade/launches.go` `TaskBoard.RestartSession`: TUI only, running only. Under `taskMu`:
  `tr.TerminalOf`, `tr.Stop` (marks stopped now, skips Reconcile grace, op-log `session/stop` trigger user via
  `recordSessionEnd`), `b.deps.CloseTerminal(terminalID)` (blocks until exit), then `takeOverLocked(..., opRestart)`.
  Headless is refused ("only an interactive session restarts").
- Headless stop exists: `TaskBoard.StopRun` (`internal/ade/runs.go:1447`), bridge `adeTaskStopRun`, button in
  `AdeSessionActions.vue` (no confirm). Run becomes `stuck`, note "stopped by you". Must not run with `taskMu` held
  (`awaitEnd`).
- `TaskBoard.ResumeRun` (`runs.go:1218`) continues a stuck run's conversation as a new attempt via
  `queueRun(..., runOpts{Launch: AdeRunLaunch{ResumeID, Prompt, Note}})`; only when `run.Launch.ResumeID` is set (app
  restart path). `launch` (`runs.go:~570`) inserts the new headless session row synchronously and sets
  `run.SessionID`; `cmpNonEmpty(spec.ResumeID, newID)` keeps the agent conversation id.
- No close call for an interactive session exists.
- Phone hold: terminal exit reaches `mobileterm.Broker.Exited` (`CloseExit`), so closing the PTY ends the hold. No
  change needed.
- Selected-tab fallback: `AdeSessionsTab` `current = running.find(ui.sessionId) ?? running[0]`. Already handles a
  closed selection.

## Decisions

1. **Close session** = end the live process, keep history.
   - Interactive (TUI), running: same as Restart's first half. `tr.Stop` then `CloseTerminal`. Row goes `stopped`,
     stays in the sessions dropdown, resumable by Take over. Works whichever window holds the PTY.
   - Headless, running: `StopRun(rec.RunID)`. Same effect as the existing Stop button.
   - Not running: refused, "the session is not running".
2. **Restart session** = end the process and continue the same conversation in a fresh one.
   - TUI: unchanged (existing `RestartSession`).
   - Headless (new): only for a plain step run (`run.Purpose == ""`) that is running and has an
     `AgentSessionID`. `StopRun`, then under `taskMu` queue the next attempt resuming `rec.AgentSessionID`
     (prompt `llmprompts.RunResumeLine`, note new const `noteRestarted = "restarted by you"`). Returns
     `adewire.Launch{SessionID: <new session id>, Cwd: rec.Cwd}` with empty `TerminalID`/`Command` (no PTY to
     open). If the attempt waits behind the worktree gate, `SessionID` is `""`. Rebase and review runs refused:
     "this run restarts from its own panel".
3. **No confirm dialog** for either. Nothing is lost beyond the in-flight turn: a closed TUI resumes by Take over, a
   stopped headless run keeps its worktree and resumes by Take over or Retry. Matches the existing Stop button and
   Restart, neither of which confirms.
4. **Labels**: SPEC wording. New keys `space.ade.sessionTab.close.label` "Close session",
   `space.ade.sessionTab.restart.label` "Restart session". `common.action.restart.label` stays (docker-ui uses it).
   Order: Restart session, Close session, separator, Copy session ID. Icons: `debug-restart`, `close`, `copy`.
5. **Visibility**: Close and Restart only when `view.session.state === 'running'` (strip tabs always are; P437 may
   reuse the menu for dropdown rows). Headless Restart disabled with hint `space.ade.sessionList.waitingId.status`
   while `agentSessionId` is empty, like Copy. Both items disabled while either action is pending for that session.
6. **One new IPC**: `AdeTaskService.CloseSession(CloseSessionArgs{SessionID}) error`. One method for both modes so
   the UI never branches on mode to pick a call.
7. **Op-log**: no new kind. TUI close logs `session/stop` trigger user (`Tracker.Stop`). Headless close logs through
   the run op (cancelled). Headless restart's new attempt logs `session/resume` (`opResume`, chosen by `launch`
   when `ResumeID != ""`).
