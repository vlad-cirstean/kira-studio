## Decisions

1. **One sessions dropdown for every session in scope**, not only stopped ones. Groups: Running, then Finished or
   stopped. Reason: the strip hides overflowing tabs with no scrollbar; the dropdown becomes the switcher that always
   reaches them, and it carries P436's Close and Restart on running rows (streams.md expects that). Group headings
   reuse `space.ade.allSessions.running.label` / `.stopped.label` ("Running 2", "Stopped 3"), matching All sessions.
   A heading shows only when both groups have rows.
2. **Trigger**: toolbar button `Sessions` (new `space.ade.sessionList.trigger.label`), total count in `rowMeta`,
   `chevron-down`. When a running session not visible as the selected tab needs input (`kind === 'input'`), an
   `AdeActivityIcon kind="input" bare` sits before the label. Shown when the scope has at least one session.
   Archived task: no trigger (inline list, as today).
3. **List = shadcn-vue `Command`** (`ignoreFilter`, own filtering through `v-model:search`) inside `PopoverContent`
   (`w-[28rem] p-0`). Own filtering because each row needs sibling content (actions, log) that the built-in item
   filter cannot hide with it. Arrow keys, Home/End and hover highlight come from reka `Listbox`. Enter or click runs
   the row's primary action.
4. **Filter field** (`CommandInput`, placeholder new `space.ade.sessionList.filter.placeholder` "Filter sessions")
   only when the list has 6 or more rows (`FILTER_FROM = 6`, named const). Matches, case-insensitive, against
   `tabName`, `branch`, `repo`, `step`, short id and full `agentSessionId`. Matches highlight with
   `HighlightedText`. No match: `InlineState kind="empty"` with `common.state.noMatches.empty`.
5. **Row** (`AdeSessionsRow.vue`), two lines, one look for both groups:
   - Line 1: `AdeActivityIcon` (bare), mode badge (extracted `AdeSessionBadge.vue`, same classes as the strip),
     `tabName`, right-aligned relative age.
   - Line 2 (`rowMeta`): state label (`activityLabel(kind)`; for a headless row with a run, `runStateLabel(run.state)`,
     amber for `stuck`/`failed`, as `AdeAllSessionRow` tones), branch or `space.ade.needs.scope.spec.label`,
     `shortId`.
   - Primary action (Enter / click): running = select that tab (`ui.sessionId`), popover closes, strip scrolls it into
     view; stopped = Take over (`useAdeTakeOverStore().request`), popover closes; archived = Resume when
     `agentSessionId` is set (`resumeArchived`), else toggles the log of a headless run, else none. A `Kbd` hint of the
     primary action label shows on the highlighted row only (`common.action.open.label`,
     `common.action.takeOver.label`, `common.action.resume.label`). Pending take over shows a `Spinner` in place of
     the hint.
   - Trailing actions, siblings of the `CommandItem` (never nested in the option), `rowActions` visibility plus
     visible while the row is highlighted, `tabindex="-1"`: `Show log` / `Hide log` toggle for a headless row with
     `runId` (`space.common.showLog.label` / `hideLog.label`, icon `output`), and More actions
     (`common.moreActions.tooltip`, `ellipsis`) opening the row menu at the button.
   - The log (`AdeRunLog`, `max-height="160px"`) renders below its row, outside the option.
   - Right-click on a row and Shift+F10 / ContextMenu key on the highlighted row open the row menu.
6. **Row menu = `useSessionMenu`**, extended, still driven by `SessionView` only:
   - `items(view, { archived, extra })` adds, for a stopped session, Take over (or Resume when archived) first, and
     for a headless session with a run, the log toggle the row passes as `extra` (row-local state). Running:
     Restart, Close, separator (P436, unchanged). Always Copy session ID last.
   - New `openFor(el, view, opts)` beside `open(ev, view, opts)`, through `openContextMenuFor`.
   - The strip keeps calling `open(ev, view)`; its menu is unchanged.
7. **Reveal**: `ui.revealSessionId` for any session in scope (running or stopped) opens the dropdown with that row
   checked through `Command`'s `model-value`, so reka highlights and scrolls to it. Running ids keep today's
   behaviour (select the tab, no popover): `AdeSessionsTab`'s watch only opens the popover for a stopped id. The
   row's `@select` handler calls `event.preventDefault()` so a click never toggles the model value off; the
   implementer confirms this against reka 2.10.5 `ListboxItem` (`select` event, `defaultPrevented`).
8. **Focus**: on open, focus goes to the filter field when shown, else to the listbox (reka `ListboxContent`), first
   row or revealed row highlighted. Escape closes and returns focus to the trigger (Popover default). Take over or
   select closes the popover first, then acts.
9. **Strip**: `AdeSessionStrip` scrolls the selected tab into view on `selectedId` change (`revealElement` from
   `@workbench/behaviour/focus`, `{ flush: 'post' }`), so a dropdown pick of an overflowed tab shows it.
10. **Names**: components renamed to what they show: `AdeStoppedMenu` to `AdeSessionsMenu`, `AdeStoppedList` to
    `AdeSessionsList`, `AdeStoppedRow` to `AdeSessionsRow`. Test ids: `ade-sessions-menu-trigger`,
    `-count`, `-popover`, `-filter`, `-empty`, `-attention`; rows `ade-sessions-row` with `data-session-id`,
    `data-state`, `data-highlighted` (from reka), `data-selected`; `ade-sessions-row-log`, `ade-sessions-row-more`,
    `ade-sessions-row-hint`; inline list `ade-sessions-list`. `ade-stopped-*` ids go away; every spec using them is
    Stream A's and is updated.
11. **`SessionView.stoppedLabel` removed** (no reader left). `allLabel`, `tabName` stay.
12. **No virtualization**: a scope holds tens of sessions at most; `CommandList` scrolls (`max-h-96`). Named here so
    the review does not ask.
13. **Libraries**: shadcn-vue `Command`, `Popover`, `Kbd`, `Tooltip` (existing; no new primitive, so no cross-stream
    duplicate), Tailwind only, VueUse not needed beyond what `revealElement` already wraps. No scoped `<style>`.
