## Findings (current tree, `8733b24`)

- Param shape: Go `scripts.Param` (`internal/scripts/smart.go:70`), zod `scriptParamSchema`
  (`packages/shared/domain/scripts.ts`). Both carry `name` and `label`.
- `name` is functional: `^[a-z][a-z0-9_]{0,31}$`, reserved vs `BuiltinVars`, unique, keys run
  values, `{name}` prompt token, `$KIRA_PARAM_<NAME>` env var, ADE step params, schedule params.
- `label` is display only. Readers: `ParamsForm.vue:31` (`p.label || p.name`),
  `scriptVars.ts:30` (`paramDetail`), `scriptVars.ts:144` (hover). Writer: `ParamsEditor.vue:119`.
  Go only trims and bounds it (`smart.go:133,141`, `MaxLabelRunes`). Never reaches a prompt or env.
- Decision: **drop `label`, keep `name`.** `name` cannot go; `label` adds nothing the run needs.
- "Path params with dotted borders": folder values rendered through `VarText` as the generic
  dashed `var-chip` (`packages/theme/src/components/VarText.vue:24`, `border-dashed border-info`):
  - `run/RunPreview.vue:40` `#folder` (and `#branch` at :38, plain var, not `kind: 'branch'`)
  - `ScriptDialog.vue:119` `folderParts` (Kira home + `/automations/` + Script ID), `:127` `homeParts`
  - `ScriptDialog.vue:396` fixed folder shown as bare `font-data` span (`script-dialog-workingdir`)
  - `run/AdeContextFields.vue:122`, `schedule/ScheduleConfirmDialog.vue:155` `#branch` as plain var
- Agent module (Kira Space ADE) branch design: `packages/theme/src/components/BranchChip.vue` —
  `Badge` (`data` font, variant `default|info|warn`), `git-branch` codicon, truncating name. Used by
  `AdeBranchRow.vue:184`, `AdeBranchPanel.vue:383,385`, and `VarText` for `kind: 'branch'`.
  Already in theme, but hard-wired to the branch icon: nothing else can reuse the recipe.
- Select params: `run/ParamsForm.vue:45` `NativeSelect` dropdown; multiselect `:57` Popover +
  Command dropdown. `ParamsForm` is shared by `RunScriptDialog`, `ScheduleFields`,
  `ScheduleConfirmDialog` and ADE `AdeStepAgentFields.vue:74`, so one fix covers all four.
- Lint constraint: `scripts/check-ui-primitives.sh` U4 forbids raw `ToggleGroup` outside
  `SecondaryTabs.vue`. `SecondaryTabs` never emits empty, so an optional select cannot clear.
  Use `RadioGroup` / `Checkbox` (shadcn-vue, already in theme) for value choices; use
  `SecondaryTabs` only for the editor's type picker (always has a value).

## Shared components (packages/theme)

### `ValueChip.vue` (new) — `packages/theme/src/components/ValueChip.vue`

The BranchChip recipe, icon-agnostic. `<script setup lang="ts">`, Tailwind only.

```ts
defineProps<{
  value: string;
  icon: string;                                  // codicon name
  variant?: 'default' | 'info' | 'warn';         // default 'default'
  chip: string;                                  // data-chip attr, e.g. 'branch' | 'path'
  class?: HTMLAttributes['class'];
}>()
```

Template: `<Badge :variant data :class="cn('min-w-0', props.class)" :data-chip="chip">`,
`<CodiconIcon :name="icon" :size="12" class="shrink-0" />`, then
`<slot><span v-if="value" class="min-w-0 truncate">{{ value }}</span></slot>`. No tooltip
(callers like `AdeBranchPanel` already wrap in `AdeTip`; nesting would double it). Attribute
fallthrough keeps `data-testid` / `data-var` from callers.

### `BranchChip.vue` (rewrite, same public API)

Props unchanged (`name`, `variant`, `class`). Body: `<ValueChip :value="name" icon="git-branch"
chip="branch" :variant :class data-testid="branch-chip" />`. ADE call sites stay untouched and
now run on the shared base.

### `PathChip.vue` (new) — `packages/theme/src/components/PathChip.vue`

```ts
defineProps<{ path: string; variant?: 'default' | 'info' | 'warn'; class?: HTMLAttributes['class'] }>()
```

`<ValueChip :value="path" icon="folder" chip="path" data-testid="path-chip" ...>` with the slot
filled by `<TruncatedText :text="path" split="path" />` (theme; keeps the last segment visible,
full path in a tooltip only while cut off). Fits the ADE/branch shape: solid tinted badge, icon,
no dashed border.

### `VarText.vue` / `varText.ts`

- `TextPart` `kind` widens to `'branch' | 'path'`.
- `VarText` renders `kind: 'path'` as `<PathChip :path="p.value" :variant class="h-auto py-px
  align-middle" :data-var="p.name" :aria-label="...same theme.varText.aria...">`.
- Plain variables (prompt tokens, env rows) keep the dashed `var-chip`: those are substituted
  variables, not paths. Out of scope.
