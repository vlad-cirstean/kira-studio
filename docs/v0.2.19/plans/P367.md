P326 added it (`docs/HISTORY.md` v0.2.10 P326). No bridge, no Go, no wire hop, so no response cap or wire truncation is involved. ## 2. Root cause

Rendering, not data. Measured in scenario 1b (Studio `ui` project, 1440x960):

- `MonacoDiff` root: 160 px tall (`min-h-40`), not the intended 240 px (`h-60`).
- `.monaco-diff-editor` inside it: **0 px** tall. `.editor.modified`: 0 px.
- Screenshot: only a few px sliver of the first diff line shows under the cell list; rest of the 160 px box is empty.

Two compounding faults:

1. `packages/workbench/src/editor/MonacoDiff.vue` template root has `h-full min-h-40`. `PreviewCommandPanel.vue` line `<MonacoDiff v-if="sides" class="h-60" ...>` adds `h-60` to the same element. Both are `height` utilities; Tailwind's CSS order makes `h-full` win, so caller's `h-60` is dropped.
2. `h-full` resolves against parent `div.max-h-96.flex.flex-col` (popover body). That parent has only `max-height`, no definite height, so `height: 100%` computes to `auto`. Root box gets 160 px from `min-h-40` only. Min-height does not make a box's height definite for its children's percentages.
   Monaco 0.56 `diffEditorWidget.js:64` creates `div.monaco-diff-editor` with inline `height: '100%'`, and `ObservableElementSizeObserver` (line 135) measures that element, not our container. Its 100% against our non-definite root is 0, so `automaticLayout` lays both editors out at height 0.

Other callers are fine because they wrap `MonacoDiff` in a sized block: `PromptDetail.vue` (`div.h-80`), `CellEditorView.vue` (`div.flex-1.min-h-0` in a definite flex column). `PreviewCommandPanel.vue` is the only caller passing a height class onto the component.

## 3. Fix

### 3.1 `packages/workbench/src/editor/MonacoDiff.vue`

Make the `min-h-40` floor real for any caller: mount Monaco on an inner absolutely positioned host, so Monaco's `height: 100%` resolves against a box with definite used height (an `absolute inset-0` box's height comes from its containing block's used height).

- Template:
  ```vue
  <div ref="root" class="relative h-full min-h-40 overflow-hidden rounded-kira-sm border border-border">
    <div ref="host" class="absolute inset-0"></div>
  </div>
  ```
- Script: add `const host = ref<HTMLElement | null>(null);`. In `onMounted`, guard on `host.value` and pass `host.value` to `createDiffEditor`. Keep `root` for `syncDebugText` (the `data-kira-diff-*-text` attributes and fall-through `data-testid` stay on the outer element; `diffEditorText` reads them there).
- Update the component's leading comment by one clause: callers size it with a wrapper, not a height class on the component.

Not chosen: `cn()`/tailwind-merge with `inheritAttrs: false` to let a caller height class beat `h-full`. Every other caller already uses the wrapper pattern; one convention is simpler than adding attr plumbing.

### 3.2 `apps/kira-studio/frontend/src/views/grid/PreviewCommandPanel.vue`

Mirror the SQL branch (`<div v-else class="h-60"><MonacoHost .../></div>`):

```vue
<div v-if="sides" class="h-60">
  <MonacoDiff data-testid="pending-diff" v-bind="sides" />
</div>
```

Drop `class="h-60"` from `MonacoDiff`. Wrapper is a flex item of `max-h-96 flex flex-col`: its 240 px is definite; if many cells push the column past 384 px it flex-shrinks, and a flexed size is still definite, so `h-full` inside resolves. `data-testid="pending-diff"` stays on `MonacoDiff`'s root, so existing selectors (`diffEditorText`, `toHaveCount(0)`) keep working.

### 3.3 `docs/ARCHITECTURE.md`

Next to the P326/P327 `MonacoDiff` lines (around line 1062), add one fact: `MonacoDiff` mounts Monaco on an inner `absolute inset-0` host because Monaco's diff root is `height: 100%` and measures itself; callers size it with a wrapper block, never a height class on the component.

## 4. Test

Unit-test bar: no unit test (CSS sizing, no logic). Backend-flow half: none; no IPC or Go change (same as P326/P327). UI half: extend existing `apps/kira-studio/tests/ui/mutations.spec.ts` scenario 1b, right after the `diffEditorText` assertion, so it fails on the current tree:

```ts
const diffHost = diffPanel.locator('[data-testid="pending-diff"]');
await expect(diffHost.locator('.editor.modified .view-line').filter({ hasText: 'edited via UI' })).toBeVisible();
const diffBox = await diffHost.locator('.monaco-diff-editor').boundingBox();
expect(diffBox?.height ?? 0).toBeGreaterThan(200);
```

`toBeVisible` alone is not enough (Playwright treats a non-zero-size line inside a 0-height parent as visible when overflow is visible), hence the height check. 200 is under 240 minus borders and above the broken 0 and the 160 fallback. Confirm the new assertions fail before 3.1/3.2 (run once on the unfixed tree, or reason from the measured 0 px) and pass after.

Optionally add the same `.monaco-diff-editor` height > 0 check in `cell-editor.spec.ts` after it opens `cell-editor-diff`, only if it costs one line; do not build a new spec.
