## 1. What exists

### 1.1 Review window header

`frontend/src/ade/v2/review/AdeReviewWindow.vue` renders two bars above the three panes:

1. `TitleBarBase` (`packages/workbench/src/components/TitleBar.vue`). This is the shared drag strip: `wails-drag h-titlebar pl-titlebar-inset pr-1.5 bg-chrome` (34px tall, 78px left inset that clears the traffic lights). It holds only the muted text `space.ade.review.window.title.title` ("Review · {branch}").
2. `AdeReviewHeader.vue` is the second bar (`border-b`, `py-1.5`). It holds the task colour dot (`ade-review-task-colour`), task title (`ade-review-title`, `line-clamp-2 text-kira-lg`), `AdeRepoTag`, branch (`ade-review-branch`), base (`ade-review-base`, "Base {base}") and `AdeReviewSync` (the "Sync to GitHub · N" button) on the right. Under them is an optional second row: the uncommitted hint `FieldDescription` (`ade-review-uncommitted`, key `space.ade.review.header.uncommitted.hint`), shown when `branch.dirty.length > 0`.

The go-to-file button, next/previous change buttons and inline/side-by-side toggle (P358) are not in either bar. They are in `views/repo/RepoDiffView.vue`'s `ViewToolbar`, inside each centre diff tab. They stay as they are. The `TabStrip` row (`ade-review-tabs`) also stays.

Native chrome: review windows are built by the same `internal/shell/window.go` `Options` as every window: `MacTitleBar{AppearsTransparent, HideTitle, FullSizeContent}`, not `Frameless`. The drag region and traffic-light inset are pure CSS (`wails-drag`, `--kira-titlebar-inset-left`). So no Go or window-chrome change is needed. The merged bar must sit in `TitleBarBase` to keep the drag region and inset.

`TitleBar.vue` has two root nodes (the bar `div` and a `Teleport`), so attributes such as `data-testid` do not fall through to it. Any test id must go on a child element.

## 2. Header design

There is one bar: `AdeReviewHeader.vue` renders `TitleBarBase`, and `AdeReviewWindow.vue` stops rendering its own `TitleBarBase` and its text.

```
[78px traffic-light inset] ● Task title  [repo]  feat/branch  Base main  [N uncommitted]          (P370 slot later)
```

`AdeReviewHeader.vue` template:

```vue
<TitleBarBase>
  <div class="flex min-w-0 flex-1 items-center gap-2" data-testid="ade-review-header">
    <span class="inline-block size-2.5 shrink-0 rounded-kira-xs" :style="…" data-testid="ade-review-task-colour" />
    <span class="min-w-0 truncate text-kira-md font-medium" data-testid="ade-review-title">{{ title }}</span>
    <AdeRepoTag :code-repo-id="target.codeRepoId" :label="repoLabel" />
    <span class="min-w-0 truncate font-data text-kira-sm" data-testid="ade-review-branch">{{ target.branch }}</span>
    <span class="shrink-0 text-kira-sm text-muted-foreground" data-testid="ade-review-base">{{ … base … }}</span>
    <Tooltip v-if="dirtyCount > 0">
      <TooltipTrigger as-child>
        <Badge variant="warn" tabindex="0" class="wails-no-drag" :aria-label="hint" data-testid="ade-review-uncommitted">
          {{ t('space.ade.review.header.uncommitted.label', { count: dirtyCount }) }}
        </Badge>
      </TooltipTrigger>
      <TooltipContent>{{ hint }}</TooltipContent>
    </Tooltip>
  </div>
</TitleBarBase>
```

Rules:
- Keep all test ids (`ade-review-header` now sits on the inner flex div). Keep `space.ade.review.header.base.label`.
- Title goes to one line (`truncate`, `text-kira-md`), because the bar is 34px tall. Drop `line-clamp-2` and `text-kira-lg`.
- No `border-b` and no `flex-col`. The main window's title bar has no bottom border either; the panes start on `bg-chrome` right below.
- Uncommitted hint becomes a `Badge variant="warn"` (packages/theme `ui/badge`) with a shadcn `Tooltip` (`@theme/components/ui/tooltip`) holding the full existing hint text. Add one key `space.ade.review.header.uncommitted.label` = `"{count} uncommitted | {count} uncommitted"` (same plural form as the hint key). The badge is a focus and hover target, so it carries `wails-no-drag`. Text spans stay draggable.
- Remove `space.ade.review.window.title.title` ("Review · {branch}"): the branch is already in the bar, and the key would trip `check-catalog --unused`.
- Leave room for P370: the identity cluster is `min-w-0 flex-1` and truncates, so a later `ml-auto wails-no-drag` action group fits at the right edge. Do not add an empty slot or placeholder now. P370 adds its own group.
- `AdeReviewWindow.vue`: drop the `TitleBarBase` import and element. Render `<AdeReviewHeader :target="target" />` first in the column. `useReviewContext` stays (it supplies `repoLabel` for the agent panel).
