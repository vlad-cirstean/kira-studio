## Colour rule (design decision)

Colour stays only where it carries meaning a user acts on:

1. Task status tag (task action cell, `tall`): keeps its tone. Status tones are user data (P379).
2. Red: failure, blocked, bad step, red branch tag, danger actions.
3. Amber: the `!` needs-you circle (`AdeAttention`, unchanged), amber branch tags, stale
   merged/deployed chips (unchanged; spec pins `rgb(240, 184, 92)`), overdue note text.
4. Task colour: only the 12px dot in the card head (same as the panel header dot).
5. Selection: `focus` frame and `bg-select`. Nothing else uses `focus`.

Everything else goes neutral.
