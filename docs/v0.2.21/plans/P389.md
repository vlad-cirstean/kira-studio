### Session close and open today (restart semantics source)

- `TaskBoard.TakeOver` (`internal/ade/launches.go:131`): stopped TUI record resumes the same record
  (`PrepareArgs.Resume = rec.ID`, `claude --resume`, recorded cwd); moved cwd falls back to the gate
  path with `Resumes = rec.AgentSessionID` (new record); review purpose relaunches the review agent;
  `launchGate` re-checks worktree and setup (`E_PREPARING` while setup runs). `ensureNotOpen` refuses
  a running TUI record ("the session is already open").
- Closing: only `archive.go` `closeTaskTerminals` closes TUI terminals (`deps.CloseTerminal` =
  `terminal.Registry.Close`, synchronous: SIGHUP, waits for exit). The record stops later via
  `Tracker.Reconcile` on `Registry.OnChange`, but Reconcile skips a record inside its grace window
  (30 s from spawn). So close-then-TakeOver from the frontend would fail "already open" for up to
  30 s, and races Reconcile after it.
- Frontend: `state/adeTakeOver.ts` `launch()` = mutation, `useLaunchOpener().open(l)` (tracks and
  opens the terminal), then selects the session. Old terminal entries are reaped by
  `state/adeTerminals.ts` once the sessions push shows them stopped and the local PTY exited.

Decision: restart is a backend call so stop, close and reopen are ordered in one place.

## Design decisions

1. **Plan:** delete row 1. Refresh all moves to the right end of the repo row. The "Plan" title is
   already the shell tab (`ade-tab-plan`); dropped.
2. **Panel:** `AdePanelFrame` loses its `PanelHeader` for both task and branch mode. The frame is
   shared; a branch-only header would keep a bar whose sole content is the caption "Branch", which
   the back link and branch name already give. Actions render at the right end of the tab row.
3. **Restart:** only for a running interactive (TUI) session, review agent included. Semantics =
   stop the record now, close its terminal (wait for exit), then exactly `TakeOver` of that record:
   same record, `claude --resume <agent session id>`, recorded cwd (gate path if moved), same
   provider, Space MCP grant re-registered. A headless run gets no Restart: its reopen is Take over
   (already in the row and the step line) and a re-run is the step's Retry. No confirm dialog: the
   conversation resumes; only an in-flight turn is cut, which the user asked for.
   Equivalence note: a TUI that came from taking over a stuck run loses its `finish_step` grant on
   restart, same as closing it and taking over from Finished or stopped today. Not a regression.
4. **Failure:** if the reopen fails (setup pending, worktree gone), the session stays stopped and the
   error shows in `ade-panel-action-error`; Take over from Finished or stopped retries.
5. **Menus** use the workbench context menu store (`useContextMenuStore`, U48 rule), not a new
   shadcn ContextMenu: every ADE right-click menu goes through it. Tooltips use theme `Tooltip`
   (shadcn-vue). Clipboard via `useCopy` (`@workbench/behaviour/clipboard`).

### 1. Go: restart a running interactive session

`internal/ade/tracker.go`:

- Extract `forgetLocked(recordID string) (lastActive int64, ok bool)`: removes `byRecord`, `live`,
  `spawnedAt`, `lastActive` (returned; `now` when absent), `agentSessionID`, `fresh`, and stops and
  deletes `graceTimers[recordID]`; `ok` false when `byRecord` has no entry. `Reconcile`'s per-record
  delete loop calls it (no behaviour change).
- New:

```go
// Stop ends a live record now, skipping Reconcile's grace window: its terminal is about to be
// closed on purpose (Restart). ErrSessionNotRunning when no live terminal is tracked for it.
func (t *Tracker) Stop(recordID string) error
```

  Lock, `forgetLocked`, unlock; `!ok` returns `ErrSessionNotRunning`. Then `Store.MarkStopped(
  recordID, lastActive)` (error returned), `OnChange()`, `OnStopped(recordID)` (read under `mu`, as
  `Reconcile` does), none with the lock held.

`internal/bridge/adewire/wire.go`, next to `TakeOverArgs`:

```go
type RestartSessionArgs struct {
	SessionID string `json:"sessionId"`
}
```

`internal/ade/launches.go`, after `TakeOver`:

```go
// RestartSession closes a running interactive session and resumes its conversation, as Take over
// does for a stopped one. Stop runs before the close so the exit's Reconcile finds nothing to do.
func (b *TaskBoard) RestartSession(ctx context.Context, args adewire.RestartSessionArgs) (adewire.Launch, error)
```

  1. `tr, err := b.tracker()`.
  2. `rec := b.deps.Sessions.Get(args.SessionID)`; nil or `TaskID == ""`:
     `invalid("session %s is not a task session", id)`.
  3. `rec.Mode != model.AdeSessionModeTUI`: `invalid("only an interactive session restarts")`.
  4. `rec.State != model.AdeSessionStateRunning`: `invalid("the session is not running")`.
  5. `b.deps.CloseTerminal == nil`: `invalid("interactive sessions are not available")`.
  6. `terminalID, ok := tr.TerminalOf(rec.ID)`; `!ok`: same "not running" error.
  7. `tr.Stop(rec.ID)`; `errors.Is(err, ErrSessionNotRunning)` maps to the "not running" error;
     other errors returned.
  8. `b.deps.CloseTerminal(terminalID)` (blocks until the process exits, so the resumed `claude`
     never shares the conversation file with the old one).
  9. `return b.TakeOver(ctx, adewire.TakeOverArgs{SessionID: rec.ID})`.

  Do not take `taskMu` here: `TakeOver` takes it and Go mutexes are not reentrant.

`internal/bridge/adetask.go`, after `TakeOver`: `RestartSession(ctx, args adewire.RestartSessionArgs)
(adewire.Launch, error)` with `validateAdeItemID(args.SessionID, "sessionId")` and `adeTaskError`.
