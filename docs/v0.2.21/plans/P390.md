  Memory, Terminal) ranks features, not top bar order: unchanged.
- Docs naming the order: `apps/kira-space/README.md:8`, `docs/ARCHITECTURE.md:832`.

## Decisions

1. New order: Agents, Automations, Memory, Git (`['ade', 'automations', 'memory', 'git']`).
   Relative order of the other three stays.
2. Default start module stays `git` (frontend default and Go `WindowModes.Default`). The row asks
   for order only; first-launch module is a separate behaviour. Changing it would also change every
   UI spec booting through `mockRuntime.ts`'s `windowsEnsure: { mode: 'git' }`. If the user wants
   Agents as the start module, that is its own row.
3. Numeric shortcuts: none exist, so nothing follows. Do not add any.
4. Stored user state: no migration. Persisted mode is a name, so each window reopens in the same
   module, now at a new position.
