# P350 plan: collapsed run shows tip, then placeholder

Spec row: `docs/v0.2.17/SPEC.md` P350.

## What "first" means (read from code)

`packages/git-core/src/graph/rowPlan.ts` `collapseRuns` (lines 280-340) walks `order`, the display
order from `localTopoOrder`, top to bottom. A run reads tip-first and oldest-last (its own comment, line
283-284). A collapsed run today pushes three entries:

1. `pushCommit(order[start])`: the **tip** (newest, top row).
2. `'collapsed'` placeholder: `storeRow: order[start + 1]`, `hiddenCount: length - 2`, hiding
   `order[start+1 .. end-2]`.
3. `pushCommit(order[end - 1])`: the **oldest** member (bottom row, the branch's first commit in
   time).

The user wants "the collapsed rows directly, then the top (tip) commit", and drops the "first"
commit. The first commit in time is the run's oldest member, display row 3 above. Read bottom-up from
the fork point, the new shape is placeholder then tip. In display order (top-down) it is **tip, then
placeholder**. The placeholder hides every member except the tip, `hiddenCount: length - 1`. The tip
cannot go below the placeholder: `projectLayoutInput` asserts no upward link (parent display row >=
child display row), and the tip is a child of the hidden rows.

Dropped row: `order[end - 1]`, the run's oldest commit (fixture: `feature-newer oldest (F4)`).

## Change

`packages/git-core/src/graph/rowPlan.ts` `collapseRuns`, collapse branch only:

```ts
pushCommit(order[start], groupIndex);
// `length > MIN_COLLAPSIBLE` (>3) guarantees at least 3 hidden rows here.
const placeholderDisplayRow = entries.length;
entries.push({ kind: 'collapsed', storeRow: order[start + 1], groupIndex, hiddenCount: length - 1 });
for (let i = start + 1; i < end; i++) {
  storeRowToContainingDisplayRow[order[i]] = placeholderDisplayRow;
}
start = end;
```

Remove the trailing `pushCommit(order[end - 1], groupIndex)`.

Keep `MIN_COLLAPSIBLE = 3`, so a run of 3 or fewer stays full. The user asked only to drop the oldest
row, not to collapse shorter runs. A 4-run now saves 2 rows instead of 1.

Doc comments to update in the same file:
- `MIN_COLLAPSIBLE` (line 96-97): drop "tip + placeholder + oldest" wording. Say a run of 3 or fewer
  renders in full; a longer one becomes tip plus a placeholder.
- `collapseRuns` header (280-284): name the shape, tip then placeholder, the oldest member hidden too.
- `RowPlanEntry.storeRow` (55-58) stays correct: the first hidden member is still `order[start + 1]`.

Blast radius checked with `codegraph_explore` (`collapseRuns`, `buildRowPlan`, `CollapsedRowContext`,
`collapsedMessageText`, `createGraphFormatter`, `GridKeyboardDeps`): nothing reads "the row after a
placeholder is the oldest".
- Formatters (`columns.ts` `messageFormatter`, `authorFormatter`, `dateFormatter`, `rowMetadata`) branch
  on `entryAt(row).kind` and `hiddenCount` only.
- `graphColumn.ts` `readSlice` draws the collapsed node from `entryAt`.
- `projectLayoutInput` maps hidden rows through `containingDisplayRow`. So the old oldest row's parent
  link (to the fork parent, e.g. M1) now leaves the placeholder, still downward, still one deduped
  link.
- Search reveal (`App.vue` `revealAndSelectSha`) and keyboard toggle use
  `displayRowOf === -1` and `containingDisplayRow`, unchanged.
No git-ui code change. No backend change.
