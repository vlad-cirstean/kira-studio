# P355 plan: ADE branch styling

Spec row: branch chips and rows across the ADE module use dotted borders and blue text. Restyle in
line with the rest of the design language (shared primitives, Tailwind tokens).

Base: `8f7ab3111`. One sequential Sonnet implementer. No stream split: `VarText.vue`, `varText.ts`
and `catalogParts.ts` feed every site below.

Pure restyle. No wire, Go or behavior change, so no backend flow test. Proof is a new visual
baseline plus updated UI-spec selectors.

### Design-language equivalent

- Git graph branch badges: `packages/git-ui/src/lib/refBadges.ts:153-213` plus
  `badgeClass.ts:7-9`: `badgeVariants({ variant })` from `@theme/components/ui/badge/variants`,
  `font-data`, codicon `git-branch` (`BADGE_ICONS.localBranch`), truncating label. Stacked branch
  uses `info`, stale uses `warn`. Solid tint, no border.
- Git `BranchPicker.vue:419-427`: `PickerTrigger` with leading `git-branch` codicon and a plain label.
- `Badge` (`packages/theme/src/components/ui/badge/Badge.vue`) variants `default` (bg-field,
  text-muted-foreground), `info`, `warn`; `data` prop adds `font-data`.

Git-ui badges are plain DOM, so no Vue component exists to share. One new theme component holds the
recipe for every Vue site.

### Target style

- New `packages/theme/src/components/BranchChip.vue`: `Badge` (variant `default` | `info` | `warn`,
  `data`) + `CodiconIcon name="git-branch" :size="12"` + truncating name span. No border, no
  `text-info` on the default variant.
- `TextPart` object gains optional `kind?: 'branch'`. `VarText` renders a branch part as
  `BranchChip`; other parts keep the variable chip unchanged.
- Base marker: `BranchChip`. Grey tone uses `default`, blue tone (someone else's branch) uses `info`,
  pending uses `warn` (replaces the dashed amber border). `info` matches git graph's stacked badge.
- Review branch name: `text-fg`. Review identity stays on the owner pill and the row stripe.
- Base picker: plain label like git `BranchPicker`; options plain `font-data` text.
- Branch panel: `BranchChip` for the name, inside the link when a URL exists.

### Out of scope, kept as is

- Real template-variable chips: workflow graph (`AdeStepNode.vue:242`, `AdeStepInspector.vue:131`,

  previews, `syncParts` shas. Per `docs/ARCHITECTURE.md:2373` those stay `VarText` variable chips.
- Dashed borders that are not branches: `AdeTaskCard.vue:101`, `:105`, `:161`,
  `AdeTaskPanel.vue:151` (parked/draft/ripple cards), `AdeDayBand.vue:109`, `:136`, `:194`,
  `AdePlanView.vue:360`, `:397`, `AdeDayControls.vue:24`, workflow nodes, `AdeSessionStrip.vue:37`.
- Blue text that is not a branch: owner pill `AdeBranchRow.vue:192` (ADE tone Badge), PR number link
  `AdeBranchPanel.vue:405`, `AdeLinkRow.vue:53`, `AdeStepBlock.vue:258`, `AdeAllSessionRow.vue:33`,

Scope is smaller than "whole module" reads: branches have one root (VarText path) plus three direct
sites (base marker, review name, panel link, base picker). The other dashed and blue classes in
`ade/` are status or non-branch signals.
