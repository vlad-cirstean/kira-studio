| P297 | Memory: distill collapses into memory; rules. Decisions final (user, 2026-10-18). The gate (`memory.gate.system`), the import extract and finalize prompts and the no-challenge mode stop treating an imperative as non-durable: they still refuse one-off tasks and questions, and still require a reason. Today distill chunks and distils each part in an isolated call and only concatenates the lines, so duplicates across parts survive: the merge pass of import's finalize step 1 is shared, not rewritten. With no store the merge covers the input only; the call never reads the store. (3) One mode: the `instructions` mode is removed; the one prompt keeps rules as short imperatives and facts as claims, negations, numbers, units, names, paths and template variables verbatim. (6) Outputs of one pipeline: stored memories, merged lines (no store), `.memory.md` doc.
