# P326: Pending changes show a real diff

Spec row: "In the SQL data view, a pending edit currently shows the new value as one long string;
show before and after as a diff, like code."

One sequential Sonnet implementer. Frontend only, no Go, no IPC change. P327 (cell editor diff)
runs next and reuses the component and helper built here; P326 builds nothing P327-only.

## Audit (CodeGraph)

- Pending-change UI is `views/grid/PreviewCommandPanel.vue`, a popover off DataView's
  `toolbar-preview-command`. It renders `previewPending`'s SQL in a read-only `MonacoHost`. An edit
  shows as one `UPDATE … SET "col" = '<whole new value>' WHERE …` line. No before value anywhere.
- Store is `views/grid/pendingChanges.ts` (`usePendingChangesStore`). `PendingEdit` is
  `{ key: RowKey; changes: Record<string, string | null> }`. Only the new value is kept.
- Writers of `edits`: `stageChange` (via `stageEdit`, `stageNull`; `paste.ts` and
  `SlickGridHost.vue:2011` call `stageEdit`), `discardCellEdit` (rebuilds `{ key, changes }`),
  `discardRowChange`, `stageDelete`, `clearPending`. `buildPlan` reads only `key`/`changes`.
- Before value is reachable only while the row is on the loaded page: `cell(tabId, row, col)` in
  `views/grid/page.ts` (`CellView { text, isNull, truncated }`). An off-page edit (`offPageCount`)
  loses it after a page change. So capture it at stage time.
- Truncated cells are not editable (comment in `duplicateAsInsert`), so a captured before value is
  always the full stored text.
- Existing diff code:
  - `packages/workbench/src/llmPrompts/PromptDiff.vue`: generic read-only Monaco diff
    (`original`/`modified` props, `createDiffEditor`, wordWrap on, `data-kira-diff-*` debug attrs).
    Only caller `PromptDetail.vue:173`. Hardcodes `'plaintext'`.
  - `httprequest/ResponseDiffDialog.vue`: inline `createDiffEditor`, dialog-specific.
  - `kira-space/.../useDiffEditor.ts`: git-file specific (URIs, transport).
  - `docker-ui/src/lib/editDiff.ts`: field-level `from`/`to` strings, not a text diff.
- Format helpers to reuse: `celleditor/detect.ts` `detectFormat`, `celleditor/formats.ts`
  `FORMAT_LANGUAGE`, `canBeautify`, `beautifyFor` (json/xml lossless indent).
- Test seam: `tests/ui/support/editorText.ts` `diffEditorText(container)` reads
  `data-kira-diff-{original,modified}-text`.
- Tabs primitive: `@theme/components/SecondaryTabs.vue` `variant="segmented"` (pattern in
  `workbench/ApprovalStatement.vue`).

## Library decision

Monaco's diff editor (`monaco-editor` 0.56.0, already a dependency). No hand-rolled diff, no new
library. It gives line plus intra-line highlights, syntax colouring, and auto inline layout below
its `renderSideBySideInlineBreakpoint` (default 900px) via `useInlineViewWhenSpaceIsLimited`
(default true). A popover and P327's dock are both narrower, so they render inline with no option.

## Design

### 1. Shared component: `packages/workbench/src/editor/MonacoDiff.vue`

`git mv packages/workbench/src/llmPrompts/PromptDiff.vue packages/workbench/src/editor/MonacoDiff.vue`,
then generalize. Lives in workbench so both apps and P327 import it as `@workbench/editor/MonacoDiff.vue`.

- Props: `original: string`, `modified: string`, `language?: EditorLanguageId` (default `'plain'`).
- Model language: `monacoLanguageIdFor(props.language)` from `@workbench/editor/monacoLanguages`
  at create; a `watch(() => props.language)` calls `mod.editor.setModelLanguage` on both models.
- Options stay PromptDiff's (read-only, `originalEditable: false`, `renderMarginRevertIcon: false`,
  `renderGutterMenu: false`, `automaticLayout`, `renderSideBySide: true`, wordWrap on, no minimap,
  `scrollBeyondLastLine: false`). Add `hideUnchangedRegions: { enabled: true }` (same as
  ResponseDiffDialog) so a large indented JSON shows only changed hunks.
- Keep `syncDebugText` and the value watch. Keep `mod` in a module-level `let` after mount (needed
  for `setModelLanguage`); never a ref (MonacoHost rule).
- Guard the async mount: after `await loadMonaco()`, return if unmounted (`root.value` null). Already
  there; keep.
- Root stays one element, so `data-testid` falls through to the node carrying `data-kira-diff-*`.
- Update `PromptDetail.vue` import: `import MonacoDiff from '@workbench/editor/MonacoDiff.vue'`,
  tag `<MonacoDiff :original="view.defaultText" :modified="text" />`. No behaviour change there.
- Comment at top: one line, "Read-only Monaco diff of two texts. Inline below Monaco's width
  breakpoint."

### 2. Shared helper: `apps/kira-studio/frontend/src/views/shared/celleditor/valueDiff.ts`

Pure function, reused by P327 with a `SelectedCell`'s column.

```ts
export interface ValueDiffSides { original: string; modified: string; language: EditorLanguageId }
export function valueDiffSides(
  before: string | null,
  after: string | null,
  column: { typeClass: TypeClass; dataType: string; name: string },
): ValueDiffSides
```

- Format: `detectFormat({ text: after ?? before ?? '', typeClass, dataType, columnName: name })[0].format`.
- NULL side becomes `''` (the row badge below says NULL; a literal text "NULL" would be ambiguous).
- If `canBeautify(format)`: `beautifyFor(format, text, 'indented')` on each non-null side. Use the
  indented texts only when every non-null side returns `ok`; else both raw. Mixed would fake a diff
  over whitespace.
- `language = FORMAT_LANGUAGE[format]`.
- No unit test (CLAUDE.md bar: two conditions over existing tested helpers).

### 3. Store: capture before value — `views/grid/pendingChanges.ts`

- `PendingEdit` gains `original: Record<string, string | null>` (comment: "page value per column
  when first staged; edits off the current page keep it").
- `stageChange`: keep `existing.original[column]` if present; else read from page:
  `const page = getPage(tabId); const col = page?.columns.findIndex((c) => c.name === column) ?? -1;`
  `const view = col >= 0 ? cell(tabId, row, col) : null;` and
  `original[column] = view && !view.isNull ? view.text : null`. `cell` and `getPage` are already imported from `./page`.
- `discardCellEdit`: drop `column` from `original` along with `changes`; rebuild
  `{ key, changes: rest, original: restOriginal }`.
- `buildPlan`, `rawStagedValue`, `pendingOnPage` unchanged (read `changes` only).
- New reactive getter for the panel:

```ts
export interface PendingCellDiff { id: string; keyLabel: string; column: string; before: string | null; after: string | null }
function editedCells(tabId: string): PendingCellDiff[]
```

  One entry per `(row id, column)` in `edits`, in Map insertion order, columns in `changes` order.
  `id = rowId + '\u0000' + column`. `keyLabel` = key columns sorted with `compareNatural` (same as
  `computeRowKey`), joined `name = value`, `, `; a NULL key value prints `nullCellText()`. Export it
  from the store's return object.
- Column descriptor for `valueDiffSides`: panel looks it up from `getPage(tabId)?.columns` by name.
  If the page no longer has it (column hidden), pass `{ typeClass: 'text', dataType: '', name }`
  (`TypeClass` in `@shared/protocol/page` has `'text'`).

### 4. Panel: `views/grid/PreviewCommandPanel.vue`

- `view = ref<'changes' | 'sql'>('changes')`. `cells = computed(() => store.editedCells(tabId))`.
  `hasEdits = cells.length > 0`. `shownView = hasEdits ? view : 'sql'`.
- `SecondaryTabs variant="segmented"` shown only when `hasEdits` (ApprovalStatement pattern), items
  `changes` / `sql`, testids `preview-command-view-changes` / `preview-command-view-sql`.
- SQL query (`useQuery`) gets `enabled` ANDed with `shownView === 'sql'`: SQL is fetched only when
  shown. Keeps the existing `gcTime: 0`, `staleTime: 0`. Loading/error/empty states unchanged for SQL.
- Changes view:
  - List (`data-testid="pending-diff-list"`, `role="list"`, `max-h-24 overflow-auto`, `aria-label`
    below). One `Button variant="toolbar" size="kira"` per cell, `:aria-pressed` = selected,
    `data-testid="pending-diff-item"`, `:data-column`. Content: `keyLabel` in a
    `font-data text-muted-foreground` span, then the column name. When `before` or `after` is
    NULL, a `Badge` (default variant) with `t('studio.common.nullValue.label')` on that side,
    order `before → after` only for the NULL case (reuse the `→` pattern ResponseDiffDialog uses).
  - `selectedId = ref<string | null>(null)`; `selected = computed(() => cells.find(id) ?? cells[0])`
    so a discarded selection falls back to the first.
  - Diff below: `<MonacoDiff class="h-60" data-testid="pending-diff" v-bind="sides" />` with
    `sides = computed(() => valueDiffSides(selected.before, selected.after, columnDescriptor))`.
    `h-60` matches the SQL view's box.
- Popover width `w-120` to `w-160` (Tailwind numeric spacing, same scale). Keep `max-h-96` outer
  cap: header + tabs + `max-h-24` list + `h-60` diff fits 24rem; if it overflows in the real
  render, drop the list to `max-h-16`, never an arbitrary value.
- Title copy changes (below): panel now shows more than SQL.
