# P322: MCP required params enforced at schema level

Base commit `214d9418a` (branch `v0.2.10`). One sequential Sonnet implementer; no stream split
(dbmcp, agentmcp and memory edits all depend on the new `llmprompts` helper).

## How schema enforcement works today

- Every Kira MCP tool registers via `mcp.AddTool` (go-sdk v1.8.0) with `InputSchema` from
  `llmprompts.InputSchema[T]` (`internal/llmprompts/schema.go:18`), which calls
  `jsonschema.For[T]` (jsonschema-go v0.4.3).
- jsonschema-go rule (`infer.go:61`, `:342`): a field without `omitempty`/`omitzero` lands in
  `required`. A tagged field is optional.
- go-sdk validates arguments against `InputSchema` before the typed handler runs
  (`mcp/server.go:402`). A failure becomes an `IsError` tool result:
  `validating "arguments": validating root: required: missing properties: ["path"]`.
  A `minLength` failure reads `minLength: "" contains 0 Unicode code points, fewer than 1`.
  Both name the field. Reuse this rejection; never duplicate it in handlers.
- Gap: `required` only means "key present". `""` or `[]` still pass, so a required string the
  handler cannot use (empty `connectionId`, empty `query`) slips through to a vague downstream
  error or a silent no-op.

## Change 1: `llmprompts.RequireNonEmpty` helper

Add to `internal/llmprompts/schema.go` after `InputSchema`:

```go
// RequireNonEmpty sets minLength 1 (string) or minItems 1 (array) on each named top-level property.
// A name not in sch.Required, or not a string/array, panics: both are programming errors.
func RequireNonEmpty(sch *jsonschema.Schema, props ...string) *jsonschema.Schema
```

- Use `jsonschema.Ptr(1)` (or a local `one := 1`) for `MinLength` / `MinItems`.
- Type check reads `prop.Type` (`"string"` / `"array"`). For a pointer or nullable field jsonschema-go fills `Types`, not `Type`. Panic on those: no caller needs them.
- Top-level only. Nested item fields (`items.fact`, `groups.key`) already get exact
  validation in `memory.validateItem` / `validateGroups`, with clear errors.
- No new dependency; jsonschema-go is already in `go.mod:27`.

## Audit

"Required in practice" means the handler fails, or silently does nothing useful, without a
non-empty value. "Change" uses: **NE** = wrap with `RequireNonEmpty`; **REQ** = drop
`omitempty` so the key becomes schema-required; **H** = new handler check; `-` = none.

the AI decide every call. The handler then refuses `""` where the kind needs a database.
