- Dialog sizes: `packages/theme/src/components/ui/dialog/index.ts:24`. `2xl` is `w-225`
  (900px); `fixedHeight` with `2xl` is `h-160` (640px), capped `max-w-[90vw]`, `max-h-[85vh]`.

## Design decisions

- Highlight with `MonacoHost readonly`, not `monaco.editor.colorize` into a `<pre>`.
  `paintOverlayHtml` (`packages/workbench/src/editor/paintSpans.ts:148`) targets one-line field
  overlays. MonacoHost already covers large docs, loading state, selection and copy, and has a
  test hook. It also matches the existing SQL viewer (`DefinitionView`).
- Format with the existing `formatConsoleText`. No new library: sql-formatter is already the
  formatter. `keywordCase: 'preserve'` keeps tokens; only whitespace changes.
- Async format through VueUse `computedAsync` with `onCancel` aborting the worker job. It is local
  compute, not bridge state, so TanStack Query does not apply. No Pinia state: the view toggle is
  per dialog instance, so it is component-local.
- Keep an "As sent" view. The user approves exact text. A formatter bug must never be the only view of
  a statement that runs against a database. A `SecondaryTabs` segmented toggle switches
  Formatted / As sent. Default is Formatted. Hide the toggle when the formatted text equals the
  statement (nothing formatted, or a kind with no formatter).
- Force word wrap in this viewer. The old `CodeBlock` always wrapped (`whitespace-pre-wrap
  break-all`). A long "As sent" line must not hide a clause past the right edge. Add an optional
  MonacoHost prop; every other caller keeps the settings-driven wrap.
- Size: `size="2xl" fixed-height`. That is 900x640 against today's 600px-wide, auto-height
  dialog. The editor takes the body's remaining height.
- Keep Deny as initial focus. Today Deny is the first focusable control. The toggle and Monaco's
  textarea would now come first. Mark Deny `data-dialog-initial` (`DialogContent.vue:50`
  honours it) so Enter and focus stay on Deny, and Escape still denies.

### 4. New `apps/kira-studio/frontend/src/workbench/ApprovalStatement.vue`

`<script setup lang="ts">`, Tailwind only, no `<style>` block.

Props: `{ kind: string; statement: string }`.

- `connectionKind = computed(() => connectionKindSchema.safeParse(props.kind).data)`. The wire field
  is a plain string. Leave the zod schema unchanged.
- `formatted = computedAsync(async (onCancel) => …, null, { evaluating })`:
  - If `!canFormatConsole(kind)`, return `props.statement`.
  - `const ctrl = new AbortController(); onCancel(() => ctrl.abort());`
  - Inline `formatConsoleText(kind, statement)` when `statement.length <= INLINE_CHARS`, else
    `parse.run('console.format', { kind, text: statement }, { signal: ctrl.signal })`.
    `parse` comes from `useParseWorker()`.
  - Return `result.ok ? result.text : props.statement`. On a thrown error (AbortError
    included), return `props.statement`. A failed format is not an error to show: the text still
    shows, as sent.
- `view = ref<'formatted' | 'asSent'>('formatted')`.
- `canToggle = computed(() => formatted.value !== null && formatted.value !== props.statement)`.
- `doc = computed(() => view.value === 'asSent' || !canToggle.value ? props.statement : formatted.value!)`.
  While formatting runs, `doc` is the statement. MonacoHost shows it at once and swaps when the
  format resolves (inline is one tick for normal sizes).
- Template:
  - Root `div.flex.min-h-0.flex-1.flex-col.gap-1.5`.
  - `SecondaryTabs` (`@theme/components/SecondaryTabs.vue`), `variant="segmented"`, `v-if="canToggle"`,
    `v-model="view"`, `:aria-label="t('studio.dbMcp.approval.statementView.aria')"`, class
    `self-start`. Items: `{ value: 'formatted', label: t('studio.dbMcp.approval.formatted.option'),
    testid: 'db-mcp-approval-view-formatted' }` and `{ value: 'asSent', label:
    t('studio.dbMcp.approval.asSent.option'), testid: 'db-mcp-approval-view-as-sent' }`. Build
    the items in a `computed` so `t` runs at render time (U70).
  - `div.min-h-40.flex-1.overflow-hidden.rounded-kira.border.border-border` with
    `data-testid="db-mcp-approval-statement"`. Inside: `<MonacoHost :doc="doc"
    :language="consoleLanguageFor(connectionKind)" :sql-dialect="sqlDialectFor(connectionKind)"
    readonly force-wrap />`.
