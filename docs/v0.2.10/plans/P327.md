# P327: Cell editor before/after diff

Spec row: "Highlight the change between the original and the edited value in the cell editor, as a
code-style diff."

One sequential Sonnet implementer. Frontend only, no Go, no IPC change. Reuse P326's
`@workbench/editor/MonacoDiff.vue` and `celleditor/valueDiff.ts` `valueDiffSides`. Build no other diff.

## Design

### Base value

Diff base = stored value: `cell.original !== undefined ? cell.original : cell.value`.
Diff after = `doc` (the buffer). A change exists when:

```ts
base === null ? cell.value !== null || isDirty : doc !== base
```

(NULL base, buffer `''` untouched: no change. NULL base, staged `''` or typed text: change.)

### 1. `state/cellSelection.ts`

`SelectedCell` gains:

```ts
/** Stored value under a staged edit of this cell; absent when nothing is staged. The cell editor
 *  diffs its buffer against it. */
original?: string | null;
```

### 2. `views/grid/pendingChanges.ts`

New getter next to `stagedValue`, exported from the store:

```ts
function stagedOriginal(tabId: string, row: number, column: string): string | null | undefined {
  const entry = rowKeyOf(tabId, row);
  const edit = entry ? pendingState[tabId]?.edits.get(entry.id) : undefined;
  return edit && column in edit.changes ? (edit.original[column] ?? null) : undefined;
}
```

### 3. `views/grid/SlickGridHost.vue` publish watch

- In the `selected` object: `original: masked ? undefined : pendingChangesStore.stagedOriginal(props.tabId, targetRow, column.name),`
  (a staged cell is never masked today; the guard keeps a real value out of a masked publication).
- New watch source (comment: "staging or discarding the selected cell republishes, so the dock's
  value and diff base follow it"):

```ts
() => {
  const p = getPage(props.tabId);
  const t = selectionTarget();
  if (!p || !t) return undefined;
  const column = p.columns[pageColumnIndexFor(p, currentOrder(), t.col)];
  return column ? pendingChangesStore.stagedValue(props.tabId, t.row, column.name) : undefined;
},
```

Effect on `CellEditorView`'s existing watch: same key, new value, `wasDirty` is judged against the
previous publication. After a dock stage the new value equals `doc`, so it reseeds to the same text
and stages nothing twice. After a Discard the buffer reseeds to the stored value. Revert's blur race
(scenario 9) ends with the stored value either way.

### 4. New `views/shared/celleditor/useCellDiff.ts`

Keeps the view under 600 lines.

```ts
export function useCellDiff(
  cell: () => SelectedCell,
  doc: Ref<string>,
  isDirty: ComputedRef<boolean>,
): {
  available: ComputedRef<boolean>; // a change exists (rule above)
  shown: ComputedRef<boolean>;     // open && available
  sides: ComputedRef<ValueDiffSides>; // valueDiffSides(base, doc.value, cell().column)
  toggle(): void;
  close(): void;
}
```

- `open = ref(false)`; `watch(() => cellKey(cell()), close)` so a new cell starts in the editor.
- `shown` falls back to false the moment the change goes away (Revert, Escape, Discard).
- `sides` only computed when read (template reads it only under `v-if`).
- One-line top comment: "Before/after diff state for the cell editor; base is the stored value."

### 5. New `views/shared/celleditor/CellGenerateMenu.vue` (split for N10)

Move the Generate popover (template lines ~439-472, `generatePanelOpen`, `generateAnchorRef`) out of
`CellEditorView.vue` verbatim. Props `disabled: boolean`; emits `apply: [gen: Generator]`; owns its
open state, closes on apply. `CellEditorView` keeps `applyGenerator(gen)` minus the
`generatePanelOpen` line: `<CellGenerateMenu :disabled="!isEditable" @apply="applyGenerator" />`.
Same testids (`cell-editor-generate`, `-popover`, `-<id>`). No behaviour change.

### 6. `CellEditorView.vue`

- `const { available: diffAvailable, shown: diffShown, sides: diffSides, toggle: toggleDiff, close: closeDiff } = useCellDiff(() => selectedCell.value, doc, isDirty);`
- Find and diff are exclusive: `toggleDiff` handler also sets `findOpen = false`; `toggleFind` calls
  `closeDiff()`. (Find targets the main editor, absent in diff view.)
- Toolbar, inside the existing `v-if="!viewerMode"` block, after `EditBufferActions`:

```vue
<TooltipIconButton
  icon="diff"
  :label="t('git.menu.stashShow.label')"
  :pressed="diffShown"
  disabled-trigger
  :disabled="!diffAvailable"
  data-testid="cell-editor-diff-toggle"
  @click="onToggleDiff"
/>
```

  Shown on read-only cells too: viewing a staged edit's diff on stale or pending-delete data is not a
  write. Viewer docks (console, stream) never edit, so no toggle.
- Body: inside `editorBodyEl`, first child:

```vue
<div v-if="diffShown" class="flex-1 min-h-0" data-testid="cell-editor-diff-pane">
  <MonacoDiff data-testid="cell-editor-diff" v-bind="diffSides" />
</div>
<template v-else> …existing encoded / decoded / timestamp blocks unchanged… </template>
```

  `MonacoDiff` is `h-full` inside a `flex-1 min-h-0` box, so it fills the dock body at any dock
  height. Inline layout at dock width (Monaco breakpoint). Monaco loads only when first shown.
- Clicking the toggle from the editor moves focus to the toolbar, so the existing `focusout` stages
  the edit first. Entering the diff never drops an edit. Escape inside the diff keeps its meaning
  (reset buffer), which hides the diff since the change is gone.
- `ResponseFindBar` line unchanged.
- Import `MonacoDiff from '@workbench/editor/MonacoDiff.vue'`.
