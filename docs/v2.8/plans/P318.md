# P318 plan: git host abstraction

One sequential implementer, one phase (no Part split, see §10). Base `v2.8` at `dacebd6` (P317 done).

## Ask

SPEC row: GitHub is the only git host. Add provider-neutral interfaces (auth and account, repository
and remote identity, pull/merge requests, reviews and comments, CI status, URL building, API client)
behind a registry and a provider setting, so another host (GitLab) plugs in without caller edits.
GitHub stays the only implementation, behavior unchanged. No back-compat shims, data loss
acceptable. Key test: a fake second host registered through a test option, driven by the same flows
with no caller change.

Same pattern as P316: neutral types plus role interfaces, one registry, a selector, a setting,
UI labels from provider info, a fake second provider in a flow test and a UI spec.

## 2. Design

### 2.1 Packages

- `apps/kira-space/internal/githost`: neutral types, role interfaces, `Registry`, `Selector`,
  setting constants, `Info`. Imports stdlib only. Space-only (no Studio caller), so it lives under
  the Space app, unlike P316's root `internal/harness`.
- `apps/kira-space/internal/githost/github`: the only provider. `git mv` every `ghclient` file and
  test into it; package clause `github`. Code bodies unchanged. New `provider.go` adapts `Client`
  to the roles (thin delegation plus the neutral-type conversion). `Repo.Path()` stays as unexported
  `apiPath(repo)` here (API escaping is GitHub's).
- `apps/kira-space/internal/githost/providers`: `New(gh github.Options, extra ...githost.Provider)
  *githost.Registry`, GitHub first. The one line a new host adds.
- `apps/kira-space/internal/flowharness/fakehost`: test-only fake second host (§6).

Import rules: `githost` imports no app package. `githost/github` imports `githost`, `toolexec`,
`procgroup` only. Callers (`gitsession`, `gitrpc`, `bridge`, `ade`, `mobileweb`) import `githost`;
only composition roots (`appwire`, `flowharness`) import `providers` or `github`.

### 2.2 Neutral term

"Change request" is the neutral name for a GitHub pull request, GitLab merge request, Bitbucket
pull request or Gerrit change. Code uses the full word (`ChangeRequest`, `changeRequest`): no `CR`
or `MR` shortening (CLAUDE.md: no invented abbreviations). User-facing text never says "change
request": it renders the provider's own term (`Terms`, §2.5).

### 2.3 Go types and roles

```go
package githost

// Repo is one hosted repository. Owner may be a nested group path for hosts that allow one.
type Repo struct{ Host, Owner, Name string }

// ChangeRequest is one pull or merge request (was ghclient.PR, same fields).
type ChangeRequest struct {
	Number    int    `json:"number"`
	Title     string `json:"title"`
	URL       string `json:"url"`
	State     string `json:"state"` // "open" | "draft" | "merged" | "closed"
	HeadRef   string `json:"headRef"`
	HeadSha   string `json:"headSha"`
	HeadOwner string `json:"headOwner"` // was HeadRepoOwner; "" when the source repo is gone
	BaseRef   string `json:"baseRef"`
	UpdatedAt int64  `json:"updatedAt"` // Unix ms
}

// Status is a host call's actionability (was ghclient.Status).
type Status struct {
	Kind        string   `json:"kind"` // KindOK | KindNotFound | KindUnauthenticated | KindForbidden
	Path        string   `json:"path,omitempty"`    // CLI path, when the host uses one
	Version     string   `json:"version,omitempty"`
	Host        string   `json:"host,omitempty"`
	Account     string   `json:"account,omitempty"`
	Probed      []string `json:"probed,omitempty"`
	Reason      string   `json:"reason,omitempty"`
	RateLimited bool     `json:"-"` // arms the per-repo breaker
}
func (s Status) OK() bool

const (KindOK = "ok"; KindNotFound = "notFound"; KindUnauthenticated = "unauthenticated"; KindForbidden = "forbidden")

// Link is a pasted issue or change-request link a provider recognised.
type Link struct {
	Provider string `json:"provider"`
	Kind     string `json:"kind"` // "changeRequest" | "issue"
	Ref      string `json:"ref"`  // display ref, GitHub "repo#12"
}

// ChangeFiles is a change request's files with the viewer's viewed state (was ghclient.PullFiles).
type ChangeFiles struct {
	NodeID, HeadSha string
	Open            bool // was State == "OPEN"
	Files           []ChangedFile // {Path string; Viewed bool}
	Truncated       bool
}
```

Roles. `Provider` composes the mandatory ones; each caller depends on the narrowest.

```go
type Provider interface {
	ID() string    // setting value, "github"
	Terms() Terms  // display text, resolved from the catalog (§2.5)
	Remotes
	Auth
	ChangeRequests
	URLs
}

// Remotes is repository and remote identity.
type Remotes interface {
	ParseRemote(remoteURL string) (Repo, bool)
	// Claims reports whether host belongs to this provider, for auto detection.
	Claims(ctx context.Context, host string) bool
}

// Auth is the host account the user is signed in as. A provider owns its credentials; Kira holds none.
type Auth interface {
	Status(ctx context.Context, host string) Status
	Account(ctx context.Context, host string) string
}

type ChangeRequests interface {
	ForCommit(ctx context.Context, r Repo, sha string) ([]ChangeRequest, Status)
	// ForBranch includes closed ones, newest first.
	ForBranch(ctx context.Context, r Repo, branch string) ([]ChangeRequest, Status)
	// Open is the repo-wide open snapshot, bounded by the provider.
	Open(ctx context.Context, r Repo) ([]ChangeRequest, Status)
}

// URLs builds and checks browser links. Composed server-side only.
type URLs interface {
	ChangeRequestURL(r Repo, number int) string
	RepoURL(r Repo) string
	BranchURL(r Repo, branch string) string
	// IsChangeRequestURL re-validates a composed URL right before the OS browser opens it.
	IsChangeRequestURL(ctx context.Context, u *url.URL) bool
	ParseLink(raw string) (Link, bool)
}

// FileReviewSync is optional: the host stores per-file viewed state on a change request.
type FileReviewSync interface {
	ChangeFiles(ctx context.Context, r Repo, number int) (ChangeFiles, Status)
	SetFilesViewed(ctx context.Context, r Repo, nodeID string, paths []string, viewed bool) (failed map[string]string, s Status)
}
```

GitHub mapping (byte-identical behavior):
- `ParseRemote` = `ghclient.ParseRemote`. `Claims(host)` = old `IsGitHubHost(host, Discovery.Hosts())`
  (`github.com`, or a host with an ok `gh auth status`).
- `Status`/`Account` = `Discovery.Status`/`Client.Account`.
- `ForCommit`/`ForBranch`/`Open` = `PullsForCommit`/`PullsForBranch`/`OpenPulls`, argv unchanged
  (argv goldens in moved `pr_test.go`, `api_test.go` prove it).
- `RateLimited`: `provider.go` sets it on every returned `Status` with the existing
  `isRateLimited` predicate, so the breaker arms on exactly today's statuses. `gitsession`'s
  duplicate `isRateLimitedStatus` (`gh.go:449`) is deleted.
- `ChangeRequestURL` = `https://<host>/<apiPath>/pull/<n>` (today `PrBrowserURL`); `RepoURL` =
  `https://<host>/<apiPath>` (today `RepoWebURL`); `BranchURL` = `RepoURL + "/tree/" + branch`
  (today `AdeBranchPanel.vue:147`, same unescaped bytes).
- `IsChangeRequestURL` = today's `OpenPullRequestURL` check: `https`, `Claims(u.Host)`,
  `pullRequestPath` regex.
- `ParseLink` = today's `GITHUB_RE` (`panelFacts.ts:20`) ported to Go: `github.com` only,
  `issues|pull`, ref `<repo>#<n>`.
- `ChangeFiles`/`SetFilesViewed` = `PullFiles`/`SetFilesViewed`; `Open` = `State == "OPEN"`.
- GitHub implements `FileReviewSync`.

Not added (resolved ambiguity, §11): no CI-status role and no comments role. GitHub has zero call
sites for either; an interface with no caller is unused scaffolding (CLAUDE.md). "Reviews and
comments" maps to `FileReviewSync`, the only review-side GitHub call. A later CI or comment feature
adds an optional role the same way, no caller edits. "API client" stays provider-private: GitHub's
is the `gh` CLI (`Runner`, `Discovery`, `Locator`); a GitLab provider brings its own HTTP client.

### 2.4 Registry, selector, setting

```go
type Registry struct{ /* byID, ordered ids */ }
func NewRegistry(ps ...Provider) *Registry // duplicate ID panics
func (r *Registry) Get(id string) (Provider, bool)
func (r *Registry) All() []Provider        // registration order
// ParseLink asks each provider in order.
func (r *Registry) ParseLink(raw string) (Link, bool)
// IsChangeRequestURL is true when any provider accepts u.
func (r *Registry) IsChangeRequestURL(ctx context.Context, u *url.URL) bool

const (
	SettingAuto = "auto" // detect from the origin remote's host
	SettingOff  = "off"
)

type Selector struct{ Registry *Registry }

// Resolve picks the host for one repository. off -> none. A registered id -> that provider, if it
// parses remoteURL. auto, "", or an unknown id (slog.Warn) -> the first provider, in registration
// order, that parses remoteURL and Claims its host.
func (s Selector) Resolve(ctx context.Context, setting, remoteURL string) (Provider, Repo, bool)
```

Setting: per-repo leaf `kiraSpace.gitHost.provider` (string: `auto` | `off` | provider id, default
`auto`) replaces `kiraSpace.github.enabled` (bool, default true). Per repo, not app-wide like
`agent.provider`: the host is a property of each repository's remote, and today's switch is
already per repo. `auto` reproduces today exactly (GitHub claims `github.com` plus authenticated
GHES hosts); `off` reproduces `github.enabled = false`. An explicit id forces a provider for a
self-hosted host its `Claims` cannot recognise (additive; never the default). Go:
`GitRepoSettings.GitHostProvider string json:"gitHostProvider"`, patch `*string`, stored leaf
`gitHostProvider`, read with `appsettings.LeafValid` and a syntax check
(`^(auto|off|[a-z][a-z0-9-]{0,31})$`); registration is not checked on write (P316 rule: a removed
provider's id still boots, `Resolve` falls back).

How a repo's remote picks its host: `RepoEntry.hostRepo(ctx)` (was `githubRepo`) runs the one
`git remote get-url origin` spawn, calls `Selector.Resolve(setting, url)` and caches `{setting,
provider id, Repo, ok}` until `refsChanged` (as today) or until the setting read on this call
differs from the cached one. A provider change also drops `hostState` caches (snapshot, branch,
commit, breaker), so facts never cross hosts. Every caller that read `githubEnabled()` now reads
`hostRepo` (off and no-match both yield "disabled", as today).

Wiring: `gitsession.Registry.Gh *ghclient.Client` becomes `Registry.Hosts githost.Selector`
(default `providers.New(github.Options{})`). `appwire.Options.GhLocator` becomes
`appwire.Options.GitHosts *githost.Registry` (nil -> `providers.New(github.Options{})`).
`github.Options{Locator ghclient.Locator, Runner, Clock}` (nil -> real ones) keeps the gh test seam.
`flowharness`: `WithoutGh` builds `providers.New(github.Options{Locator: noGhLocator{}}, extra...)`;
new `WithGitHost(p githost.Provider)` appends `p`.
