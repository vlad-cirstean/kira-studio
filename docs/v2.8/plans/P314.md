## Decisions

### 1. Where the setting lives

Kira Space settings leaf `memory.claudeModel` in `kira.db`'s `settings` table. App-wide, not per
project.

- Existing mechanism: draft plus Save, reset-to-default, `kira:settings:changed` broadcast all
  come free. A store in `memory.db` would either break the draft rule (ARCHITECTURE:1244) or need
  a composite settings bridge, and reading it at settings load would create `memory.db` for users
  who never touch memory (`internal/memory/store.go:33-34` promises lazy creation).
- Not per project: distill of pasted text and the MCP gate often have no project; `memory.db` is
  one global store.
- No migration: new leaf row, absent means default.

Cross-process read, resolved fresh per Claude call (like git settings, ARCHITECTURE:1620):

- App process: `repos.Settings.GetAll()` on the open handle.
- `memory-mcp`, `memory-ingest` children: open `config.DbPath()` per call, `GetAll` through a
  `repos.SettingsRepo{DB: db}`, close. Missing file means default, no error, and never create the
  file (stat first: `sqlitex.Open` would create it). Per-call open costs milliseconds against a
  Claude call of seconds; no lingering handle on another process's DB. WAL plus `_busy_timeout`
  5000 from `sqlitex.BuildDSN` covers the concurrent app writer.
- A change applies from the next Claude call in every process, including a running import and a
  registered MCP server, with no restart or re-registration.

### 2. Allowed values

- Aliases `haiku`, `sonnet`, `opus`. Not full model IDs: the CLI resolves an alias to the current
  model of that family, so the list never goes stale; the CLI has no list-models command to source
  IDs from; smart scripts already use exactly these aliases.
- One Go list: new leaf package `internal/claudemodel` (`Aliases`, `Default = "sonnet"`,
  `Valid(string) bool`). `internal/scripts/smart.go:60` becomes `Models = claudemodel.Aliases`;
  `DefaultModel` stays its own constant (smart-script default, same value by coincidence of policy).
- One TS list: new `packages/shared/domain/claudeModels.ts` (`CLAUDE_MODELS`, `ClaudeModel` type,
  `DEFAULT_CLAUDE_MODEL`). `scripts.ts:26` becomes `SMART_MODELS = CLAUDE_MODELS`.
- Validation: `model.SettingsPatch.Validate` rejects anything outside `claudemodel.Aliases`
  (error names leaf `memory.claudeModel`, same shape as `validateMobileSection`); TS settings schema
  uses `z.enum(CLAUDE_MODELS)`.
- Invalid stored value (manual edit, a future alias removed): `LeafValid` keeps default `sonnet`;
  UI shows `sonnet`. `CLIRunner` re-checks `claudemodel.Valid` on whatever the source returns and
  falls back to default with `slog.Warn`, so a bad source never reaches `--model`.
- Read error (locked or corrupt `kira.db`): `slog.Warn`, use default. Memory features keep working;
  the documented safe model is the default.

### 3. One resolver, every site

`internal/memory/claude.go`:

```go
// ModelSource returns the model alias for the next call; nil means claudemodel.Default.
type ModelSource func() (string, error)

type CLIRunner struct {
	lookPath func(string) (string, error)
	stat     func(string) (os.FileInfo, error)
	models   ModelSource
}

func NewCLIRunner(models ModelSource) *CLIRunner
func (r *CLIRunner) model() string // nil source, error or invalid alias -> claudemodel.Default (warn on the latter two)
func ClaudeAvailable() error       // package-level probe; CLIRunner.Available delegates
func claudeArgs(model string, c Call) []string
```

Delete `claudeModel` const. `RunResult` calls `claudeArgs(r.model(), c)`. Nil-means-default
matches `ClaudeAgent.Prompts` (`importer/extract.go:47`).

- `memoryModelFrom(r *repos.SettingsRepo) memory.ModelSource` (app process).
- `memoryModelAt(dbPath string) memory.ModelSource` (children; stat, open, `GetAll`, close).
