The panel, as specified

A working drawing of the git graph panel described in docs/SPEC.md — sitting where the terminal sits, at the bottom of the window. The lane graph below is a real layout pass over a real commit topology, drawn to canvas, repainting when you change the theme. Everything else is presentation.

Try it: click a commit to open the pane and click it again to close. Right-click any row for the actions. Click a sha to copy it.

Not built

Nothing in the repository implements this yet — P0 has not started. This is a mockup drawn from the spec, so it is a proposal to argue with, not a screenshot. Where it and SPEC.md disagree, the spec is what agents will build.
