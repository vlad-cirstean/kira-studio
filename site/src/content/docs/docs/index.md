Two native macOS apps share one repository.

**Kira Studio** is a database client for ten engines plus an HTTP and gRPC API client. It also has Automations and Docker modes.

**Kira Space** is a git client and code workspace. It adds coding agents, a memory store, a terminal and a phone view on your home network.

## Platform

- macOS 26 or later, Apple Silicon only.
- Dark mode only.
- Beta. Expect bugs and breaking changes between builds.
