## Browse

The grid is virtualized in both directions. Page sizes are 10, 100, 1000 and 10000. The default is 100; change it in `Settings > Data`.

- The total row count runs on request. Click the count in the pager, tooltip "Count all rows".
- Column projection limits which columns load.
- Find searches the current page.

## Filter and sort

Type a server-side `WHERE` and `ORDER BY`. The app keeps a history of filters and lets you save them.

## Edit

SQL tables stage edits. Add, delete and edit rows as a pending change set. The preview shows the exact command.

Nothing reaches the database until you click **Commit pending changes**. Document, key/value and stream writes apply immediately.

## Cell editor

A Monaco panel detects JSON, XML, SQL, base64, hex, epoch, ISO-8601, UUID, URL and CSV. It offers beautify and compact.

## Foreign keys

Preview a referenced row in a popover. Then open it in a pre-filtered tab, or jump straight to editing it. This works on PostgreSQL and MariaDB.

## Generate data

Fill a SQL table with fake rows. Recipes per column come from the column types.

## Operations panel

The panel lists every database operation live. Each row shows duration, rows and command. You can cancel and re-run an operation. A persisted log keeps older operations; `Settings > Advanced` sets retention, 1 to 365 days, default 30.
