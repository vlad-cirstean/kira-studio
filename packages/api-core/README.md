# @kira/api-core

Pure, DOM-free TypeScript for the Api module (P12): `{{name}}` substitution, curl parse/generate,
raw HTTP parse/generate, the dynamic-value catalog, and the two protocols' saved-request mappers.
No Vue, no DOM, no `apps/` import — see `docs/HISTORY.md (v1.2 P12)`
(D6, D7) for what stays here and what stays in the app.
